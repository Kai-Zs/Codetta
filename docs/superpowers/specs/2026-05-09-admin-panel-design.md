# Codetta 管理员后台设计文档

## 概述

在 `/admin` 下新增完整管理后台，包含题目管理、用户管理、数据统计、系统设置四大模块。

**核心约束：数据库表结构不变，仅修改前后端代码。**

## 路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/admin` | AdminHome | 后台首页（重定向到题目管理） |
| `/admin/questions` | AdminQuestions | 题目管理（搜索/编辑/新增/停用） |
| `/admin/users` | AdminUsers | 用户管理（搜索/重置PIN/查看详情） |
| `/admin/stats` | AdminStats | 数据统计面板 |
| `/admin/settings` | AdminSettings | 系统设置（维护模式/管理员密码） |

原 `/admin/reset-pin` 路由移除，功能合并到 AdminUsers。

## 鉴权

- 管理员密码存储在 `backend/.env` → `ADMIN_PASSWORD`
- 前端：进入 `/admin/*` 时，先检查 sessionStorage 中是否有 `admin_token`
- 若无：显示密码输入弹窗，输入正确后存 `admin_token`，后续请求 header 带 `X-Admin-Password`
- 后端：`/api/admin/*` 路由统一校验 `X-Admin-Password` header
- 管理员密码与用户登录 token 相互独立

## 页面设计（大屏/PC）

### 整体布局
- 动态背景与前台一致（渐变 + 几何图案动画）
- 内容区使用类似手机壳的卡片容器，但比例更大、更适合 PC 屏
- 左侧侧边栏 + 右侧主内容区，两张卡片并排

```
┌──────────────────────────────────────────────────┐
│                                                  │
│              （动态背景层）                       │
│                                                  │
│   ┌──────────┐  ┌────────────────────────────┐   │
│   │ Codetta  │  │                            │   │
│   │  Admin   │  │                            │   │
│   │          │  │      主内容区              │   │
│   │ 题目管理 │  │   （列表/表单/图表）       │   │
│   │ 用户管理 │  │                            │   │
│   │ 数据统计 │  │                            │   │
│   │ 系统设置 │  │                            │   │
```

### 卡片样式
- 左侧边栏卡片：宽 200px、自适应高度、20px 圆角、双层紫边框、白底/暗黑底
- 右侧内容卡片：flex-1 自适应宽度、同样圆角/边框/背景
- 两张卡片间距 16px，整体居中

### 设计 Token（与前台统一）
- 主色：`#7C3AED`（紫）
- 卡片背景：白 / 暗黑 `#1a1a2e`
- 卡片边框：双层紫边框（与手机壳一致）
- 标题字体：Georgia
- 正文：系统默认
- 按钮：紫色主按钮 / 红色危险按钮 / 灰色次要按钮
- 表格：圆角、淡灰边框、hover 高亮
- 弹窗：居中缩放动画（与 SettingsPanel 一致）
- 侧边栏菜单项：hover 时紫色高亮、当前页加粗紫色

## 模块详情

### 1. 题目管理（/admin/questions）

**搜索栏**
- 题号搜索（模糊匹配）
- 题型筛选（下拉）
- 章节筛选（下拉）
- 每页 20 条分页

**列表**
| 题号 | 题型 | 标题（截断） | 状态 | 操作 |
|------|------|-------------|------|------|
| 1.1 | 单选 | 以下代码的输出... | 启用 | 编辑 / 停用 |

- 点击"编辑"→ 编辑弹窗（见下方）
- 点击"停用"→ 确认后 `UPDATE is_active=0`
- 列表底部"新增题目"按钮

**新增/编辑弹窗**
- 题型选择（单选/判断/填空/编程）
- 题号（手动输入）
- 章节（1-8）
- 标题
- 题干（textarea）
- 根据题型动态显示：
  - 单选：选项编辑器（添加/删除选项行，每行 A/B/C/D + 文本） + 正确答案选择
  - 判断：正确答案（正确/错误单选）
  - 填空：答案输入（$ 分隔多空）
  - 编程：模板代码编辑器（小号 textarea/CodeMirror）+ 答案代码编辑器
- 备注
- 保存按钮

### 4. 系统设置（/admin/settings）

- **维护模式**：开关按钮
  - 开启 → 创建 `backend/maintenance.lock` 文件
  - 关闭 → 删除该文件
  - 前端全局路由守卫：维护模式开启时，非管理员访问任何页面 → 显示维护提示页面

- **修改管理员密码**：输入旧密码 + 新密码 + 确认新密码 → 更新 `.env` 中的 `ADMIN_PASSWORD`

- **题库重载**：按钮 → 调 seed（高危操作，二次确认 + 警示文字）

## 后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/admin/verify | 验证管理员密码 |
| GET | /api/admin/questions | 题目列表（搜索+分页） |
| PUT | /api/admin/questions/:id | 修改题目 |
| POST | /api/admin/questions | 新增题目 |
| GET | /api/admin/users | 用户列表（搜索+分页） |
| GET | /api/admin/users/:id | 用户详情+答题记录 |
| POST | /api/admin/users/:id/reset-pin | 重置用户 PIN |
| GET | /api/admin/stats | 统计数据 |
| GET | /api/admin/settings | 获取设置状态 |
| POST | /api/admin/maintenance | 切换维护模式 |
| PUT | /api/admin/password | 修改管理员密码 |
| POST | /api/admin/reload-seed | 重载题库 |

所有 `/api/admin/*` 路由校验 `X-Admin-Password` header。

## 前端实现

### 组件树
```
App.vue → AdminLayout（/admin/* 路由共用）
├── BackgroundLayer（复用）
├── AdminSidebar（左侧导航卡片）
│   ├── 标题 "Codetta Admin"
│   ├── 题目管理（router-link）
│   ├── 用户管理
│   ├── 数据统计
│   ├── 系统设置
│   └── ← 返回前台
└── AdminContent（右侧主内容卡片）
    └── router-view
        ├── AdminQuestions.vue    # 题目管理
        ├── AdminUsers.vue        # 用户管理
        │   └── AdminUserDetail.vue  # 用户详情
        ├── AdminStats.vue        # 数据统计
        └── AdminSettings.vue     # 系统设置
```

### 关键逻辑
- **路由守卫**：进入 `/admin/*` 先检查 sessionStorage 的 `admin_token`，无则弹密码输入
- **密码验证**：POST `/api/admin/verify`，成功后存 sessionStorage
- **维护模式**：App.vue 的全局路由守卫检查 `/api/admin/maintenance` 状态，非 Admin 页面显示维护提示
- **AdminLayout**：两张卡片并排，左侧 `w-[200px]` 固定宽，右侧 `flex-1`，间距 16px，整体居中
- 复用现有 Toast/ConfirmDialog/LoadingSpinner 等通用组件
- 管理后台完全不走手机壳 PhoneShell，独立布局
