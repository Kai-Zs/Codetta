# 练笔小筑 — 手机悬浮窗视觉重设计

## 概述

将练笔小筑所有页面从全屏布局改为"动态背景 + 手机悬浮窗"的视觉方案，统一套在 340×9:16 手机壳内。编程题编辑器和手机并排显示。

## 动态背景

- 底色：鲜色渐变（紫→蓝→粉→紫）
- 图案：单层圆点+叉号几何图案，56px 间距 45° 平铺
- 动画：整个图案层向右上方匀速平移（CSS transform translate，约 7s 循环）
- 性能：使用 transform 动画，不触发 reflow
- 可访问性：`prefers-reduced-motion` 时静止

## 手机悬浮窗

- 尺寸：340px 宽，aspect-ratio 9/16
- 圆角：20px
- 边框：双层色框（#d4c0f0 + #b8a0e0）模拟手机中框
- 阴影：淡紫投影 `0 24px 80px rgba(100,40,180,0.15)`
- 内部：白色背景，可滚动内容区，顶部 44px 状态栏
- 位置：水平居中，编程题时左移给编辑器腾空间

## 全局 App 结构

```
App.vue
├── 动态背景层（固定全屏，pointer-events: none）
├── 手机壳容器（router-view 内容在此渲染）
└── 编辑器浮层（仅编程题时显示，Teleport 到 body）
```

`App.vue` 提供手机壳外框，各页面视图只需关注内部内容。

### 刷题页（编程题）

手机左移 + 右侧浮出代码编辑器大面板。

```
┌──── 动态背景 ──────────────────────────┐
│                                         │
│  ┌─────────┐   ┌──────────────────┐     │
│  │ ← 8.15  │   │ 代码编辑器   Python│     │
│  │ 编程题   │   │                  │     │
│  │         │   │ def fib(n):      │     │

│  │ 函数... │   │     return n     │     │
│  │         │   │   return fib...  │     │
│  │ [提交]  │   │                  │     │
│  │         │   │ [重置]  [提交判题]│     │
│  └─────────┘   └──────────────────┘     │

```

- 手机：显示题干 + 提交按钮（点击后调 AI 判题，结果在手机内显示或用 toast）
- 编辑器面板：
  - 顶部：标题 "代码编辑器" + 语言标签 "Python"
  - 中间：深色代码编辑区（textarea，等宽字体）
  - 底部：重置按钮 + 提交判题按钮
  - 进入动画：fade + 从右滑入（300ms）
- 编辑器面板尺寸：约 480px 宽，高度自适应（约 400px 代码区）
- 非编程题时不显示编辑器面板、不显示手机壳 → 只显示手机壳居中

### 错题本页

手机壳内：筛选栏（题型下拉+章节下拉）+ 操作栏（全选/重做/移出/导出）+ 错题列表（checkbox+题号+题型+标题）+ 分页。

### 设置面板

在手机壳内以弹窗/侧滑面板形式出现，包含编程题模式（write/review）、声音开关、震动开关。

## 编辑器与手机的通信

- 编辑器面板和手机内的题目组件共享同一个 `question` 数据（通过 Pinia store）
- 编辑器提交 → 调用 `/api/judge/code` → 结果同时在手机内显示（AI 评分+评语）和编辑器底部显示
- 编辑器提供 `defineExpose`（`getCode`、`reset`），手机内的提交按钮通过 store 触发编辑器提交

## 响应式与边界处理

- 手机壳 `max-width: 88vw`，`max-height: 90vh`，防止小屏溢出
- 编程题时，若屏幕宽度不足（< 340 + 480 + 间距），编辑器缩小或手机进一步缩窄
- 小于 768px 宽度时编辑器改为下方弹出而非右侧并排
- 支持 `prefers-reduced-motion`：背景图案静止，编辑器直接显示不播放入场动画

## 技术实现要点

- 动态背景：纯 CSS（渐变 + inline SVG background-image + CSS animation），不依赖 JS
- 手机壳：`App.vue` 中包裹 `<router-view />`，各页面视图无需改动壳子
- 编辑器浮层：`Teleport` 到 `body`，通过 Pinia store 的 `showEditor` 控制显隐
- 现有 `PracticeView.vue` 逻辑保持不变，只在容器层加手机壳和编辑器面板

## 不做

- 不改动路由结构
- 不改动 Pinia store 逻辑（仅新增编辑器相关状态）
- 不改动后端
- 不改动题库数据
